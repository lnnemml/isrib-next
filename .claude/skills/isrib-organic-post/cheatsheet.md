# Cheatsheet — decide fast, gate hard

## The human-gate checklist (6 boxes — output on every DRAFT)

1. **Helps first?** Answers a real person's real question before anything of ours appears.
2. **Voice clean?** Honest-skeptic; zero banned words; a caveat present.
3. **Claim safe?** No medical/dementia/cancer/guarantee claim; research-use framing; limits stated.
4. **Citations real?** Every named study/author/year/journal verified against a real source
   and it actually says what the draft claims. Unverified → mark it **[VERIFY]**, never
   present as post-ready. This is the persona's one unrecoverable failure mode.
5. **Link right?** Reddit: passes the link tree (default no-link) + disclosed. X: link last, not first.
6. **Identity safe?** Nothing that reveals Anton's real identity.

All 6 pass → "safe to post." Any fail → name it; don't present as post-ready.

## Channel-in-one-line

- **Reddit** = help, help, help; disclose; default **no link**; be most direct in r/ISRIB,
  most disciplined in r/Nootropics.
- **X** = 1 science thread/week + daily useful replies; link last; the quote-tweet is the prize.

## Reddit link decision (fast)

Direct answer? → sub allows a link *in this thread*? → past the 4–6wk ramp + 9:1 healthy? →
disclosed at the link? → **all yes = one journal link, utm-tagged.** Any no = **no link.**

## Disclosure snippets (Reddit)

- "Full disclosure: I synthesise and sell A15, so factor that in — but here's the actual chemistry:"
- "Bias disclaimer: I make this stuff. That said, the honest answer to your question is…"

## Voice quick-swaps

breakthrough→notable · revolutionary→significant · miracle→worth examining · "will fix"→"the
data suggests" · "cures"→"in animal models, reduced…" · "guaranteed"→(delete).

## Pick one belief (don't stack)

symptom question → Belief 1 · "how does it work" → Belief 2 · "I tried X" → Belief 3 ·
"is it safe" → Belief 5. Move one. Answer one objection. Stop.

## Under uncertainty

Say less. Drop the link. Keep the help. A pure-value comment is never the wrong call.
