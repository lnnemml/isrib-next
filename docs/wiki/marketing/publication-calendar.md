## Sequencing logic

Not roadmap order — **ROI order.** Front-load two things:
1. **Bottom-funnel converters** — they turn the organic traffic already arriving after the
   migration into orders (the migration equity is being defended by 301s; the job now is to
   *convert* it).
2. **Science link-bait** — the pieces X/Reddit can distribute and that earn editorial
   backlinks, which is the single biggest lever on a young (re-migrated) domain's ramp.

Each article ships **coupled** to: 1 X thread (repurpose), N Reddit answer opportunities it
unlocks, and 1 email-digest slot to the owned list.

## Refresh cycle (protects the migrated equity)

The 8 live articles carry the domain's existing rankings. Quarterly, per the losers-first
rule (organic-content-strategy §10):
- Update `updatedAt`, add 1–2 newly-surfaced **People-Also-Ask** answers in `<h2>` form.
- Add any new research via `<ResearchCallout>`.
- Tighten internal links to the *new* compare/guide pages this calendar adds.
- **First refresh pass: ~2026-12** (after wk 12), starting with the compare pages (highest
  intent) and `isrib-a15-complete-guide`.

## Migration-watch (do not skip — first 30–60 days post-cutover)

The journal domain move is recent; equity restabilises over 3–6 months. Weekly during the
Fri review block:
- **GSC:** migrated URLs indexed? 301s resolving with no soft-404s? PAA still present? any
  ranking cliff on the compare keywords?
- **Fix redirect gaps immediately** — this is the #1 risk (organic-content-strategy §11).

## Coupling map (article → distribution, same week it ships)

| Output | When | Where |
|---|---|---|
| **X thread** (6–10 posts) | Ship day +0–2 | The Synthesis Lab X; ends with article link |
| **Reddit answers** | Ongoing | Link the article **only** where a question directly calls for it + rules allow + disclosed (playbook §3) |
| **Email digest** | Batch monthly | Owned list — 2–4 newest articles per send (ties to Track B email-leadgen) |
| **HN submit** | Science pieces only (wk 4, 9, 11) | Submit the *narrative science*, not commercial pages |

## Definition of done (per article, before ship)

- [ ] Writing-rules formula (11 sections) + honest-skeptic voice, no banned words.
- [ ] Frontmatter complete (keyword-first title; belief-gate description; `keywords`,
      `relatedSlugs`, `cluster`, dates).
- [ ] 3–5 real PAA questions answered in `<h2>` form.
- [ ] Links: up to pillar + 2–3 `relatedSlugs` + ≥1 to nearest high-intent compare/guide.
- [ ] `<ResearchCallout>` cites **real** sources; `<CTABlock>` → `/products/isrib-a15`.
- [ ] Compliance pass: no medical/dementia/cancer-risk/guarantee language; research-use frame.
- [ ] Build green; visual check; sitemap includes it.
